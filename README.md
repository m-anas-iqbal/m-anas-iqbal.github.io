## 💻 Local Development

To run and preview this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/m-anas-iqbal/m-anas-iqbal.github.io.git
   cd m-anas-iqbal.github.io
   ```

2. **Serve the project:**
   You can serve the directory using any static web server:
   - **VS Code:** Use the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension.
   - **Python 3:**
     ```bash
     python -m http.server 8000
     ```
   - **PHP Built-in Server:**
     ```bash
     php -S localhost:8000
     ```
   - **Node.js (serve / npx):**
     ```bash
     npx serve .
     ```

3. **Open in browser:**
   Navigate to `http://localhost:8000` to view the site.
